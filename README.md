# World Timezones & Live GMT Index

An automated repository providing synchronized, up-to-date UTC/GMT offsets for all countries and territories, fully accounting for Daylight Saving Time (DST) switches.

## Data Files

- **`timezones.json`**: Machine-readable JSON containing all ISO country codes, IANA identifiers, DST indicators, and offsets.
- **`last_run.json`**: Automated execution log tracking timestamp and health status.
